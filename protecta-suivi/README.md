# تطبيق متابعة المشاريع والعروض — Protecta Suivi

قالب ووردبريس يحوّل الموقع إلى تطبيق ويب لمتابعة المشاريع والعروض والتسليم.
ووردبريس يُستعمل فقط كمحرّك (الحسابات، قاعدة البيانات، رفع الملفات)، والموظفون لا يرون لوحة تحكم ووردبريس أبدًا.

> الإصدار الحالي: **0.1.0** (المرحلة 1: الأساسات). انظر `CHANGELOG.md`.

---

## 1. التثبيت على HostGator (أول مرة)

1. من cPanel: ثبّت ووردبريس على النطاق (Softaculous ← WordPress) أو استعمل موقعًا موجودًا مخصّصًا لهذا التطبيق.
2. ادخل إلى لوحة تحكم ووردبريس بحساب المدير: `https://موقعك/wp-admin`.
3. **المظهر ← قوالب ← إضافة ← رفع قالب**، اختر الملف `protecta-suivi-x.y.z.zip` ثم **التثبيت الآن** ثم **تفعيل**.
4. عند التفعيل يُنشئ القالب تلقائيًا: الجداول، الأدوار (موظف / مسؤول مشروع / الإدارة)، القوائم المنسدلة الافتراضية، والإعدادات.
5. افتح عنوان الموقع: تظهر صفحة الدخول الخاصة بالتطبيق.

لا يحتاج القالب أي إضافة (plugin).

### إنشاء أول حساب للإدارة
إلى حين اكتمال صفحة المستخدمين في الإعدادات (المرحلة 5): من لوحة ووردبريس ← **المستخدمون ← أضف جديدًا**، واختر الدور **«الإدارة»** أو **«مسؤول مشروع»** أو **«موظف»**.

---

## 2. التحديث إلى إصدار جديد (بدون فقدان البيانات)

1. **احتياطًا**: خذ نسخة احتياطية من cPanel (JetBackup أو «النسخ الاحتياطي») — القالب يأخذ أيضًا نسخة تلقائية.
2. لوحة ووردبريس ← **المظهر ← قوالب ← إضافة ← رفع قالب** ← اختر الملف الجديد ← **استبدال الحالي بالمرفوع**.
3. عند أول فتح للموقع بعد التحديث، يقوم القالب تلقائيًا بـ:
   - أخذ **نسخة احتياطية JSON** كاملة في `wp-content/uploads/protecta-suivi/backups/`؛
   - تطبيق تحديثات قاعدة البيانات (إضافة فقط، لا حذف ولا مسح).

**مضمون في كل تحديث:** المشاريع، العروض، الشركات، المستخدمون، الإعدادات، القوائم المنسدلة (بأسمائها وترتيبها كما عدّلتها الإدارة) والملفات تبقى كما هي. القوائم لا تعود أبدًا إلى قيمها الافتراضية.

---

## 3. الأمان والنسخ الاحتياطي (مهم)

- **فعّل HTTPS**: في cPanel ← **SSL/TLS Status** ← فعّل شهادة AutoSSL المجانية، ثم في ووردبريس ← الإعدادات ← عام، اجعل العنوانين يبدآن بـ `https://`.
- **نسخة احتياطية يومية تلقائية**: في cPanel فعّل JetBackup (أو خدمة CodeGuard) بنسخة يومية للملفات **وقاعدة البيانات**.
- محاولات الدخول محدودة (5 محاولات خاطئة ← حظر 15 دقيقة)، وتسجيل الخروج تلقائي بعد ساعتين بدون نشاط (قابلان للتعديل في الإعدادات).
- ملفات المشاريع والنسخ الاحتياطية في `wp-content/uploads/protecta-suivi/` **محمية**: لا يمكن فتحها برابط مباشر.

---

## 4. المهمة اليومية Cron (البريد الصباحي)

*(تُستكمل في المرحلة 5.)* سيُرسل التطبيق كل صباح ملخّص المهام بالبريد. يُضبط من cPanel ← **Cron Jobs**:

```
wget -q -O /dev/null "https://موقعك/?ps_cron=الرمز_السري"
```

الرمز السري (64 حرفًا) يظهر في صفحة **الإعدادات**، ويمكن تجديده هناك (عندها يجب تحديث أمر الـ Cron).

---

## 5. أين أعدّل ماذا؟

| أريد أن أغيّر… | الملف |
|---|---|
| الألوان، الخط، الوضع الليلي | `assets/css/variables.css` |
| شكل الصفحات والمكوّنات | `assets/css/app.css` |
| شكل الطباعة / PDF | `assets/css/print.css` |
| الشعارات | `assets/img/` (logo.png، logo-banner.png، logo-marques.png) |
| صفحة الدخول | `templates/login.php` |
| رأس الصفحة والقائمة والتذييل | `templates/app-shell.php` |
| صفحة معيّنة (مهامي، المشاريع، العروض…) | `assets/js/pages/<الصفحة>.js` |
| **قواعد الحساب** (نسبة النجاح، التأخير، الأولوية…) | `inc/calculs.php` (المرحلة 3) |
| القيم الافتراضية للقوائم (للتثبيت الأول فقط) | `inc/install/defaults.php` |
| المدة الافتراضية للخروج التلقائي، محاولات الدخول… | `inc/settings.php` |
| صلاحيات الأدوار | `inc/roles.php` |
| بنية قاعدة البيانات | `inc/install/schema.php` + ترحيل جديد في `inc/install/migrations.php` |

**ملاحظة:** القوائم المنسدلة والإعدادات تُعدَّل من صفحة **الإعدادات** داخل التطبيق، وليس من الملفات.

---

## 6. هيكلة الملفات

```
protecta-suivi/
├── style.css, functions.php, index.php
├── inc/            ← منطق الخادم (PHP): الإعدادات، الأدوار، الدخول، قاعدة البيانات، الواجهة البرمجية REST
├── templates/      ← صفحة الدخول وهيكل التطبيق
└── assets/         ← CSS، JavaScript (ملف لكل صفحة)، الخطوط، الصور
```
