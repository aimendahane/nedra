# تطبيق متابعة المشاريع والعروض — Protecta Suivi

قالب ووردبريس يحوّل الموقع إلى تطبيق ويب لمتابعة المشاريع والعروض والتسليم.
ووردبريس يُستعمل فقط كمحرّك (الحسابات، قاعدة البيانات، رفع الملفات)، والموظفون لا يرون لوحة تحكم ووردبريس أبدًا.

> الإصدار: **1.2.0** — انظر `CHANGELOG.md`.

---

## 1. التثبيت على HostGator (أول مرة)

1. **ثبّت ووردبريس**: من cPanel ← **Softaculous** ← **WordPress** ← Install، على النطاق (أو نطاق فرعي) المخصص للتطبيق. احتفظ باسم المستخدم وكلمة السر الخاصين بالمدير.
2. **فعّل HTTPS**: cPanel ← **SSL/TLS Status** ← فعّل شهادة AutoSSL المجانية للنطاق. ثم في ووردبريس ← الإعدادات ← عام: اجعل «عنوان ووردبريس» و«عنوان الموقع» يبدآن بـ `https://`.
3. **ارفع القالب**: ادخل إلى `https://موقعك/wp-admin` ← **المظهر ← قوالب ← إضافة ← رفع قالب** ← اختر `protecta-suivi-1.2.0.zip` ← **التثبيت الآن** ← **تفعيل**.
   عند التفعيل يُنشئ القالب تلقائيًا: الجداول، الأدوار، القوائم المنسدلة، والإعدادات.
4. **افتح التطبيق**: `https://موقعك/` ← سجّل الدخول بحساب مدير ووردبريس.
5. **أنشئ حسابات الفريق**: الإعدادات ← **المستخدمون** ← «حساب جديد» (الدور: موظف / مسؤول مشروع / الإدارة، واربط كل حساب بالموظف المناسب من القائمة).
6. **راجع القوائم والقواعد**: الإعدادات ← **القوائم** (التصنيفات، الموظفون، الأماكن…) و**قواعد التحقق**.
7. **استورد بيانات النسخة الأولى** (اختياري): الإعدادات ← **البيانات** ← اختر `backup.json` ← **معاينة** ← تحقق ← **استيراد**.
8. **البريد الصباحي والمهمة اليومية**: انظر القسم 4.
9. **النسخ الاحتياطي اليومي**: cPanel ← **JetBackup** (أو «Backup») ← فعّل نسخة يومية للملفات **وقاعدة البيانات**.

لا يحتاج القالب أي إضافة (plugin). يتطلب PHP 8.1 أو أحدث (cPanel ← **MultiPHP Manager**).

---

## 2. التحديث إلى إصدار جديد (بدون فقدان البيانات)

1. احتياطًا: نسخة احتياطية من cPanel (JetBackup) — والتطبيق يأخذ أيضًا نسخة تلقائية.
2. لوحة ووردبريس ← **المظهر ← قوالب ← إضافة ← رفع قالب** ← اختر الملف الجديد ← **استبدال الحالي بالمرفوع**.
3. عند أول فتح بعد التحديث، يأخذ التطبيق تلقائيًا **نسخة JSON كاملة** ثم يطبّق تحديثات قاعدة البيانات (إضافة فقط).

**مضمون:** المشاريع، العروض، الشركات، الحسابات، الإعدادات، القوائم (بأسمائها وترتيبها كما عدّلتها الإدارة) والملفات تبقى كما هي. القوائم لا تعود أبدًا لقيمها الافتراضية.

---

## 3. الأمان والنسخ الاحتياطي

- **HTTPS إجباري** (الخطوة 2 أعلاه).
- **نسخة يومية تلقائية** من cPanel (الخطوة 9) — تشمل الملفات المرفقة (`wp-content/uploads/protecta-suivi/`).
- من التطبيق: الإعدادات ← البيانات ← «تحميل نسخة احتياطية الآن» (ملف JSON بكل البيانات، دون الملفات المرفقة). احفظه خارج الخادم.
- محاولات الدخول محدودة (5 ← حظر 15 دقيقة) والخروج تلقائي بعد ساعتين بدون نشاط — قابلان للتعديل في الإعدادات ← عام.
- ملفات المشاريع والنسخ الاحتياطية محمية: لا تُفتح برابط مباشر.
- الحسابات لا تُحذف، بل تُعطّل (يبقى تاريخها).

## 4. البريد الصباحي والمهمة اليومية (Cron Job)

### أ. اجعل البريد يصل (مرة واحدة)
على الاستضافة المشتركة، البريد المرسل من «wordpress@موقعك» يُرفض غالبًا أو يذهب إلى Spam. الحل: حساب بريد حقيقي.
1. cPanel ← **Email Accounts** ← **Create**: أنشئ بريدًا مثل `app@موقعك.com` واحفظ كلمة سره.
2. التطبيق ← الإعدادات ← **عام** ← «إعدادات إرسال البريد»:
   - بريد المرسل: `app@موقعك.com` — اسم المرسل: «متابعة المشاريع»؛
   - فعّل «الإرسال عبر SMTP»: الخادم `mail.موقعك.com`، المنفذ `465`، التشفير `SSL`،
     اسم المستخدم `app@موقعك.com` (كاملًا)، وكلمة السر ← **حفظ**.
3. «تجربة الإرسال»: اكتب بريدك ← **إرسال بريد تجريبي**. إذا فشل، تظهر **السبب الحقيقي** (رسالة الخادم):
   - `Could not authenticate` ← كلمة السر أو اسم المستخدم خطأ؛
   - `Could not connect to SMTP host` ← جرّب المنفذ `587` مع `TLS`، أو تحقق من اسم الخادم (في cPanel ← Email Accounts ← Connect Devices)؛
   - `Invalid address (From)` ← اكتب «بريد المرسل» صحيحًا.

### ب. فعّل البريد الصباحي
1. الإعدادات ← **عام** ← فعّل «إرسال ملخص المهام كل صباح» ← حفظ.
2. لكل حساب يريد البريد: الإعدادات ← المستخدمون ← تعديل ← «البريد الصباحي».

### ج. المهمة اليومية في cPanel (Cron Job) — ما هي ولماذا؟
ووردبريس لا يعمل إلا عندما يفتح أحدٌ الموقع. الـ **Cron Job** هو منبّه في الاستضافة يفتح «رابطًا سريًا» للتطبيق
كل يوم في الساعة التي تختارها (مثلًا 07:00)، فيرسل التطبيق البريد الصباحي حتى لو لم يدخل أحد.
1. في التطبيق: الإعدادات ← **عام** ← قسم «المهمة اليومية» ← انسخ الأمر كاملًا. شكله:
   ```
   wget -q -O /dev/null "https://موقعك/?ps_cron=الرمز_السري_64_حرفًا"
   ```
2. cPanel ← **Cron Jobs** (قسم Advanced).
3. «Cron Email» (أعلى الصفحة): اتركه فارغًا (وإلا تصلك رسالة كل يوم).
4. «Add New Cron Job» ← Common Settings: **Once Per Day (0 0 * * *)**، ثم غيّر **Hour** إلى الساعة المطلوبة
   (مثلًا `7` = 07:00 بتوقيت الخادم؛ خوادم HostGator غالبًا على توقيت أمريكا، أي 07:00 في ليبيا ≈ `0` أو `1` على الخادم — جرّب).
5. **Command**: الصق الأمر المنسوخ ← **Add New Cron Job**.
6. للتجربة فورًا: الصق الرابط (ما بين علامتي التنصيص) في المتصفح ← يجب أن يظهر `OK …`.
   الرابط مع رمز خاطئ يعطي «403» (طبيعي، للحماية).
7. «آخر إرسال» في الإعدادات ← عام يبيّن تاريخ آخر تشغيل. البريد يُرسل **مرة واحدة في اليوم** فقط، ولا يُرسل لموظف ليست له مهام.

بديل (إذا لم يعمل wget): `php /home/اسم_الحساب/public_html/wp-content/themes/protecta-suivi/cron.php`.
الرمز السري يمكن تجديده من نفس الصفحة (عندها حدّث أمر الـ Cron في cPanel).

### و. إشعارات Telegram ✈ (خطوة بخطوة)
1. **إنشاء البوت:** في Telegram افتح **@BotFather** ← أرسل `/newbot` ← اختر اسمًا (مثلًا «Protecta Suivi») ثم اسم مستخدم ينتهي بـ `bot` ← انسخ **الرمز (token)** (يشبه `123456789:AAH…`).
2. **وضع الرمز في wp-config.php (لا يُكتب في التطبيق):** cPanel ← **File Manager** ← مجلد الموقع ← افتح `wp-config.php` ← أضف قبل السطر `/* That's all, stop editing! */` هذا السطر (مع رمزك):
   ```php
   define( 'PS_TELEGRAM_TOKEN', '123456789:AAH...' );
   ```
   احفظ الملف. الرمز لا يظهر أبدًا في التطبيق ولا في النسخة الاحتياطية ولا في الصفحات.
   (المواقع التي أُعدّت قبل 1.6.0 بلصق الرمز في الإعدادات تعمل كما هي، ويُنصح بنقل الرمز إلى wp-config.php.)
3. التطبيق ← الإعدادات ← **عام** ← «إشعارات Telegram»: فعّل الإشعارات ← **حفظ** (يظهر «متصل بالبوت @…») ← **إرسال رسالة تجريبية**.
4. **ربط كل مستخدم:** 🔔 ← **ربط Telegram** ← يظهر رمز من 8 أحرف صالح **10 دقائق** ← أرسل للبوت `/start الرمز` (أو اضغط «فتح البوت وإرسال الرمز تلقائيًا») ← يصبح الحساب «مربوط بتيليغرام». الإدارة ترى حالة كل حساب في الإعدادات ← المستخدمون (عمود Telegram).
5. **فك الربط في أي وقت:** 🔔 ← «فك الربط»، أو أرسل `/stop` للبوت.
6. تصل على Telegram: إشعارات المشاريع، المهام والرسائل الصوتية، **تنبيهات الفواتير**، والملخص الصباحي (إن فُعّل «البريد الصباحي» للحساب).

### و2. الفواتير وتنبيهاتها 🧾
- الفاتورة مرتبطة بعرض (سطر في «متابعة العروض» ← زر 🧾). يمكن عدة فواتير لنفس العرض (دفعات).
- **آخر أجل للرد = تاريخ إرسال الفاتورة + 15 يومًا** (يُغيَّر في الإعدادات ← عام ← «آخر أجل للرد على الفاتورة»). يُحسب تلقائيًا ولا يُكتب.
- «جواب الحريف»: في الانتظار / نعم / لا. فاتورة في الانتظار بعد الأجل = **متأخرة** (عدد الأيام ظاهر).
- صفحة **الفواتير** في القائمة: في الانتظار، متأخرة، تم الرد… — وفي Recap: عدد الفواتير، المتأخرة، نسبة «نعم» و«لا»، والمبالغ لكل عملة على حدة.
- **التنبيهات (كل صباح مع الـ Cron):** قبل 3 أيام من الأجل، يوم الأجل، ثم مرة واحدة يوميًا عند التأخر — للموظف المتابع للعرض (وإلا المسؤول عن المشروع)، على Telegram، وإلا بالبريد. الرسالة فيها فقط: رقم الفاتورة، رقم المشروع، الأجل، نوع التنبيه، والرابط (بدون اسم الحريف ولا المبلغ).
- إن تعطّل Telegram: يُسجَّل الفشل، يُرسل بريد احتياطي، وتُعاد المحاولة في الـ Cron التالي. لا تُرسل نفس الرسالة مرتين في نفس اليوم.
- مفتاح عام: الإعدادات ← عام ← «تفعيل التنبيهات». **لا تنبيهات بدون Cron** (انظر الفقرة ج).

### و3. «مشروع؟» والملاحظات والتواريخ
- في بطاقة المشروع خانة إجبارية **«مشروع؟» نعم / لا**. «لا» يتطلب «سبب عدم اعتباره مشروعا» (قائمة في الإعدادات). المشروع «لا» يبقى في «المشاريع» (فلتر «مشروع؟») لكنه لا يظهر في العروض ولا في مؤشراتها ولا في نسبة النجاح، ويُعدّ على حدة في Recap.
- ثلاث ملاحظات منفصلة: **ملاحظة المشروع** (البطاقة)، **ملاحظة العرض** (متابعة العروض)، **ملاحظة الفاتورة** (الفاتورة). و«NOTE / نص الطلب» اختياري.
- **المسؤول والمتابع لكل عرض:** يأتيان من المشروع، ويغيّرهما مسؤول المشروع أو الإدارة من «متابعة العروض» مع **سبب إجباري** يُسجَّل في سجل التعديلات.
- **التواريخ** تُكتب وتُعرض دائمًا بصيغة يوم/شهر/سنة (مثلًا 05/10/2026)، مع زر 📅 للتقويم.
- **الترتيب (1.6.1):** في بطاقة المشروع: 📎 الملفات المرفقة أولًا، ثم «مشروع؟» (والسبب تحته مباشرة إن كان «لا»)، ثم باقي الخانات. في «المشاريع»: رقم المشروع، الاسم، مشروع؟، سبب عدم الاعتبار، المسؤول، المتابع، تاريخ الاستلام، الحالة، ثم الباقي — و«مشروع؟» عمود يُرتَّب ويُفلتر (الفلتر ظاهر دائمًا في الأعلى). في «متابعة العروض» و«الفواتير»: الأعمدة المهمة أولًا ثم الباقي، مع 📎 وعدد الملفات.
- **سهولة الاستعمال (1.7.0):** القوائم الثلاث (المشاريع، متابعة العروض، الفواتير) تعرض **8 أعمدة مهمة فقط**؛ زر «▦ الأعمدة» يضيف ما تريد (يُحفظ في المتصفح، و«الافتراضي» للرجوع). فوق كل قائمة **فلاتر سريعة بعدد العناصر** (مثلًا: الكل / مشروع / غير مشروع، أو ⚠ لازم قرار). **الضغط على سطر** (أو بطاقة في الهاتف) يفتح **لوحة جانبية** فيها كل التفاصيل والأزرار: في العروض تُعدَّل كل بيانات العرض من اللوحة (مع الملفات والفواتير). بطاقة المشروع: أزرار للانتقال بين الأقسام، والخانات الثانوية في «المزيد من الحقول» (إلا إذا كانت إجبارية).
- **«مشروع؟» من الجدول (1.8.0):** في «المشاريع» عمود «مشروع؟» فيه زرّان **نعم / لا**: «نعم» يجعل الطلب عرضًا يظهر فورًا في «متابعة العروض»، و«لا» يطلب السبب. يمكن إذن إدخال الطلب أولًا ثم القرار لاحقًا من الجدول مباشرة. «متابعة التسليم» أصبحت بنفس طريقة القوائم الأخرى (جدول قصير + فلاتر سريعة + لوحة جانبية للتعديل).
- يمكن إرفاق ملفات **عند إنشاء المشروع** (أعلى البطاقة). بيانات الشركة المختارة من الدليل (الشخص، الهاتف…) تأتي من **دليل الشركات** ولا تُكتب في كل مشروع.

### ز. الرسائل الصوتية 🎙
- في «📌 مهمة جديدة»: اضغط **🎙 تسجيل رسالة صوتية** ← تكلّم ← **إيقاف** ← استمع للتحقق ← **إرسال المهمة** (5 دقائق كحد أقصى).
- يستمع لها الموظف في «مهامي» وتصله على Telegram. يتطلب الموقع **https** (الخطوة 2 من التثبيت) والسماح بالميكروفون.
- أثناء التسجيل يظهر **شريط أخضر** يتحرك مع الصوت. إذا لم يتحرك: الميكروفون مكتوم أو غير مسموح به ← أصلحه ثم أعد التسجيل.
- تسجيلات Chrome / Android تُحوَّل تلقائيًا إلى صيغة Telegram الصوتية (Ogg) قبل الإرسال.
- إذا كان التسجيل **بدون صوت** يرفضه التطبيق برسالة «التسجيل بدون صوت». الحل في Android: إعدادات الهاتف ← التطبيقات ←
  Chrome ← الأذونات ← **الميكروفون: مسموح**، وفي Chrome: 🔒 بجانب عنوان الموقع ← الميكروفون ← سماح. أغلق أي تطبيق آخر يستعمل الميكروفون (مكالمة، WhatsApp…).

### ح. اللغات: العربية · English · Français 🌐
- في صفحة الدخول: اختر **العربية / English / Français** أسفل النموذج.
- داخل التطبيق: زر اللغة في الأعلى (**AR / EN / FR**) ← اختر اللغة. تُحفظ في حسابك (كل موظف بلغته).
- الإدارة: الإعدادات ← عام ← «لغة الواجهة الافتراضية» (للحسابات التي لم تختر لغة).
- البريد وTelegram يصلان بلغة كل مستلم. البيانات المُدخلة (أسماء المشاريع والشركات…) لا تُترجم.
- القيم التي غيّرت الإدارة اسمها في القوائم تظهر كما كُتبت في كل اللغات.

### ط. اختبار الصوت 🎙 (إذا كانت الرسائل الصوتية بدون صوت)
الإعدادات ← عام ← **اختبار الصوت**، على نفس الهاتف: ① 🔊 تشغيل نغمة (هل سمعتها؟) ② سجّل 5 ثوانٍ وأنت تتكلم ③ 🔍 تحليل التسجيل
(مع «إرسال إلى Telegram الخاص بي»). كل سطر ✔ أو ✘ يبيّن أين المشكلة: الصوت في الهاتف، الميكروفون، الخادم أو Telegram.

### ي. الميكروفون في الكمبيوتر (PC)
- إذا ظهر «لم يُلتقط أي صوت»: اختر ميكروفونًا آخر من قائمة **🎤** بجانب زر التسجيل (يُحفظ الاختيار).
- Windows: الإعدادات ← النظام ← الصوت ← **الإدخال**: اختر الميكروفون وتكلّم (يجب أن يتحرك الشريط) وتأكد أن مستوى الصوت ليس 0.
- Windows: الإعدادات ← الخصوصية ← **الميكروفون**: فعّل «السماح للتطبيقات» و«تطبيقات سطح المكتب».
- Chrome: 🔒 بجانب عنوان الموقع ← الميكروفون ← سماح (أو `chrome://settings/content/microphone` لاختيار الجهاز).

### ك. استيراد ملف Excel القديم 📊
الإعدادات ← 💾 البيانات ← **استيراد ملف Excel**: اختر الملف (.xlsx أو CSV) ← **🔍 معاينة** (لا يُحفظ شيء) ← اقرأ «خانات فارغة» و«تنبيهات» ← **📥 استيراد**.
- كل سطر = صنف، والأسطر بنفس «رقم» = مشروع واحد. الأرقام P029… تبقى كما هي.
- يمكن تصحيح الملف وإعادة استيراده: المشاريع الموجودة لا تُستبدل (تُتجاهل)، والجديدة فقط تُضاف.
- **للبدء من جديد:** فعّل «🗑 مسح كل المشاريع والمهام الحالية ثم الاستيراد» ← معاينة (يظهر «سيتم حذف N مشروع حالي + M مهمة») ← اكتب «مسح الكل» ← استيراد. تُحذف كل المشاريع وكل المهام والإشعارات. تُحفظ نسخة احتياطية كاملة قبل الحذف (يمكن التراجع من «استرجاع»). تبقى القوائم والشركات والحسابات والإعدادات.
- **حذف المهام (الإدارة):** في «مهامي» زر 🗑 بجانب كل مهمة (حذف نهائي)، وزر «🧹 تنظيف المهام» لحذف المهام المنجزة والملغاة أو كل المهام (اكتب «مسح الكل»). تُحفظ نسخة احتياطية قبل الحذف الجماعي.
- قبل الاستيراد تُحفظ نسخة احتياطية تلقائية.

### ل. ورقة حسابات الفريق 📄
الإعدادات ← 👤 المستخدمون ← **📄 ورقة حسابات الفريق**: اختر الموظفين (اسم الدخول مقترح ويمكن تغييره) ← **إنشاء الحسابات** ← **🖨 طباعة / PDF** أو **⬇ تحميل**.
كلمات السر تظهر مرة واحدة فقط. عند أول دخول تظهر لكل موظف رسالة «اربط حسابك بـ Telegram».

### م. صلاحيات الموظف
الموظف يعدّل أصنافه فقط. لا يغيّر أصناف موظف آخر ولا مبالغ العرض والشراء (حتى خلال 24 ساعة بعد إنشاء المشروع) — هذا للمسؤول عن المشروع والإدارة.

### ن. الملفات المرفقة و Google Drive 📁
- كل أنواع الملفات مقبولة (PDF، Excel، Word، صور، ZIP، DWG…) **ما عدا البرامج والسكربتات** (php، exe، bat، js، html، svg…).
- الحجم الأقصى 20 ميغابايت (الإعدادات ← عام ← «الحجم الأقصى للملف المرفق»). عند الإضافة يمكن كتابة **اسم عرض** للملف.
- الحذف: المسؤول عن المشروع والإدارة، أو من أضاف الملف خلال 24 ساعة.
- **Google Drive** (لتوفير مساحة الخادم): الإعدادات ← عام ← «تخزين الملفات — Google Drive».
  - **حساب Gmail عادي:** console.cloud.google.com ← مشروع جديد ← فعّل Google Drive API ← OAuth consent screen (External، أضف بريدك في Test users) ← Credentials ← OAuth client ID (Web application) ← الصق «رابط الرجوع» الظاهر في الإعدادات في Authorized redirect URIs ← انسخ Client ID و Client Secret في الإعدادات ← «حفظ وربط Google Drive» ← وافق.
  - **Google Workspace:** حساب خدمة (Service account) ← مفتاح JSON ← أضف بريد الحساب كـ «مدير محتوى» في Drive مشترك ← الصق المفتاح ورابط المجلد ← «حفظ وربط».
  - الملفات تُحفظ في مجلد «Protecta Suivi» (مجلد لكل مشروع). الفريق يفتحها من الموقع فقط. الملفات القديمة تُنقل تلقائيًا.

### هـ. الإشعارات 🔔
- الجرس 🔔 أعلى الصفحة يبيّن عدد التغييرات الجديدة في المشاريع التي تخصّك. اضغط عليه ← اضغط على إشعار ← يُفتح المشروع.
- **من يصله إشعار؟** مشروع جديد ← المسؤول عن المشروع + الموظف المتابع + موظفو الأصناف. صنف جديد أو أُسند لموظف آخر ← ذلك الموظف.
  أي تغيير آخر (حالة العرض، حالة المتابعة، التواريخ، المبالغ، سجل المتابعة، الملفات…) ← المسؤول + المتابع.
  من قام بالتعديل لا يصله إشعار عن نفسه. حفظ واحد = إشعار واحد يجمع كل التغييرات.
- **بريد فوري**: في نافذة الجرس، فعّل «بريد فوري عند كل تغيير» (لكل حساب على حدة؛ معطّل افتراضيًا).

### د. المهام الحرة («مهمة جديدة»)
- **الإدارة** و**مسؤول المشروع**: مهامي ← **📌 مهمة جديدة** (أو زر **📌 مهمة** في صفحة مشروع): الموظف، المهمة، الأجل، ملاحظة.
- تظهر عند الموظف في **مهامي** (قسم «مهام مُسندة»)، في عدّاد القائمة، في البريد الصباحي، ويصله بريد فوري.
- الموظف يضغط **✔ تمت**. المرسل يتابع في «مهام أرسلتها» (يمكنه التعديل أو الإلغاء). لا يُحذف شيء.

## 5. أين أعدّل ماذا؟

| أريد أن أغيّر… | المكان |
|---|---|
| القوائم المنسدلة، الخانات الإجبارية، المدد، البريد | **من داخل التطبيق**: صفحة الإعدادات |
| الألوان، الخط، الوضع الليلي، الظلال، سرعة الحركات | `assets/css/variables.css` |
| أيقونات القائمة | `assets/js/core/icons.js` |
| شكل الصفحات | `assets/css/app.css` — الطباعة: `assets/css/print.css` |
| الشعارات | `assets/img/` (logo.png، logo-banner.png، logo-marques.png) |
| **قواعد الحساب** (نسبة النجاح، التأخير، الأولوية، التنبيهات…) | `inc/calculs.php` (ملف واحد مشروح) |
| صفحة معيّنة | `assets/js/pages/<الصفحة>.js` (ملف لكل صفحة) |
| الصلاحيات حسب الدور | `inc/roles.php` و `inc/permissions.php` |
| القيم الافتراضية للقوائم (للتثبيت الأول فقط) | `inc/install/defaults.php` |
| رسائل البريد الصباحي | `inc/services/digest.php` — إرسال البريد / SMTP: `inc/mail.php` |
| المهام الحرة («مهمة جديدة») | `inc/repo/tasks.php` و `assets/js/pages/mes-taches.js` |
| الإشعارات 🔔 (من يصله ماذا) | `inc/services/notifications.php` — الجرس: `assets/js/core/notifications.js` |
| Telegram | `inc/services/telegram.php` — الرمز: `wp-config.php` (`PS_TELEGRAM_TOKEN`) |
| الفواتير | `inc/repo/invoices.php` و `assets/js/pages/factures.js` — حساب الأجل والتأخير: `inc/calculs.php` |
| تنبيهات الفواتير (من يصله، متى، نص الرسالة) | `inc/services/alerts.php` |
| أجل الرد على الفاتورة / تفعيل التنبيهات | **من داخل التطبيق**: الإعدادات ← عام |
| صيغة التواريخ (يوم/شهر/سنة) | `assets/js/core/ui.js` (enhanceDate) |
| الترجمة (English / Français) | `inc/i18n/en.json` و `inc/i18n/fr.json` (النص العربي ← الترجمة) — `inc/i18n.php` |
| بنية قاعدة البيانات | `inc/install/schema.php` + ترحيل جديد في `inc/install/migrations.php` (إضافة فقط) |

بعد أي تعديل في الملفات: غيّر رقم الإصدار في `style.css` و `inc/config.php`، ثم أعد ضغط المجلد `protecta-suivi` وارفعه كتحديث.
